# Contributing

NeatPaste v0.4.2 is a small, local Mac conversion island. Improvements should preserve a short interaction: drop files, choose a supported output, convert, and find the result.

## Develop

Install Node.js 22.12 or later, Rust 1.90 or later, and Xcode Command Line Tools. See [the README](README.md#install-and-develop) for native prerequisites.

```sh
npm install
npm test
npm run build
npm run build:native
npm run test:native
cargo test --manifest-path src-tauri/Cargo.toml --locked
npm run tauri dev
```

The browser preview helps with UI work; it cannot prove native file conversion, path permissions, window dragging, or Finder integration.

## A useful change

Explain the concrete input or interaction, expected output, and validation. Use synthetic fixtures rather than personal documents. For a format change, inspect actual generated bytes and open the result in a suitable application; a successful process exit or a changed extension is insufficient.

- Preserve original files and never overwrite an existing export.
- Keep the supported-format matrix synchronized in the UI and both READMEs.
- Make document fidelity explicit: extracting/reflowing text is different from preserving layout.
- Exercise malformed inputs, filename collisions, size limits, Unicode paths, and partially failed batches where relevant.
- Keep native file paths behind registered queue identities; do not add broad filesystem commands to the renderer.
- Justify new runtime dependencies, decoders, persistent storage, or background work.
- Keep transformations and queue decisions testable separately from the window UI.

Use narrowly scoped fixes. Formatting-only changes do not need new tests; meaningful conversion fixes should include regression fixtures where practical.

## Performance evidence

Measure a release build and record the OS, hardware, version, input dimensions or page count, and method. Include associated WebView and conversion-helper processes. Compare idle and active conversion workloads without recycling an older version's numbers. The browser preview and installer size do not describe runtime memory.

## Scope

Version 0.4.2 targets macOS; Windows is deferred. Cloud conversion, folder watching, clipboard history, OCR, PDF-to-Word layout reconstruction, and large office runtimes are outside the current design. See [the design notes](docs/DESIGN.md).
